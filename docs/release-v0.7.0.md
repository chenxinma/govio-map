# Govio Map v0.7.0 — 结果可信、口径可溯

> 覆盖 v0.6.1 之后的全部演进：**Phase 1「可信分析」与 Phase 2「语义层集成」整体验收**，
> 以及对话体验、性能与工程质量改进。govio-cli 与 Govio Map 自 0.6.1 起独立发版。

## 🧾 可信分析（Phase 1）：这个数敢不敢交给领导

- **分析留痕（Analysis Manifest）**：SQL / DataFrame 节点固化 SQL 全文、数据源、执行模型、
  行列数与结果校验和，随画布持久化，可回查每个数的来源
- **一键复跑与漂移提示**：DataFrame 节点按固化 SQL 重执行，对比行数/校验和，不一致时标记
  漂移警告并保留原留痕，不静默覆盖
- **权限确认审计**：取数/读数据等确认全程留痕（含命令改前改后），决策可回查
- **交付导出**：一键导出自包含 HTML 报告（节点 + 血缘图 + Manifest 附录 + 漂移警示），离线可看

## 🎯 语义层集成（Phase 2）：口径是不是公司口径

- **图谱定义自动注入**：提问时自动把相关指标定义、字段标准、维度码值注入上下文，SQL 生成
  即用公司口径（不再自造），注入内容随消息留痕、全程可质证
- **口径溯源与语义血缘**：SQL 节点记录本次引用的图谱实体（指标/维度/标准 ID）；画布血缘边
  区分**数据血缘**（绿色实线）与**语义血缘**（紫色虚线，口径沿袭），含图例与导出区分
- **口径冲突检测**：SQL 与图谱指标定义不一致时，SQL 节点亮**黄色警示**并给出差异说明
  （聚合口径/计量列/时间窗/过滤范围），宁可「存疑」不误报
- **SourceTable 标注**：表节点携带数据源/类型/schema/全限定表名，SQL 表引用有据可依
- **元数据增量导入与校验报告**（govio-cli 侧）：重复导入幂等固化，每次导入产出校验报告
  （计数 + 新增/更新/跳过 + 重复 ID/必填缺失/孤儿边校验）
