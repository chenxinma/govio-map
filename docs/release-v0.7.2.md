## 🤝 成果可交接（Phase 3）：画布不再只属于一个人

- **画布团队存储抽象（T3.1）**：session/画布存储接口化（本地后端行为不变），新增**逐画布
  S3 存储配置**——每个画布可绑定独立 S3 bucket/prefix（凭据走 env 引用、不落画布/导出/日志），
  多端指向同一地址即共享画布数据。写入模型为本地写 + 异步同步（If-Match 乐观锁 + 冲突
  最后写入胜出）；S3 后端为**零依赖 SigV4 实现**（无新增运行时依赖）。真实 S3 端到端已用
  RustFS 验证 15/15（签名反证 403、跨实例发现、513ms 满足秒级约束）
- **只读分享与 fork 续写（T3.2）**：`/share/<token>` 只读分享视图（含 Manifest 清单、
  T1.2 语义只读复跑）；一键 fork 出可写副本，画布级派生血缘 `forkFrom` 可追溯（抗 autosave、
  再分享继承），与数据血缘互不干扰

## 🔍 表间关系更准了（X17）

- 关系匹配升级**三级**：全限定名全等（大小写归一）命中即止 → 点号后缀变体兜底 → 不中不建边
- **跨库同名表不再误连**（如 `sales.a.dim_product` vs `sales.b.dim_product` 各连各的），
  新增 16 例自动化断言含误配对照

## 🏷️ 指标在画布可见（X18，PD-1 方案 1）

- SQL 节点卡片新增**口径徽标区**：引用的图谱指标/维度直接可见（Metric 优先、前 3 条 + 折叠、
  hover 全文、缺 code/name 自动跳过不造空徽标）
- 与口径黄色警示共存不遮挡；导出 HTML 同步「口径引用」表

## ⚖️ 口径判定升级：维度限定条件的实质比对（X19，跨仓）

- 口径冲突检测从「剔除词出现与否」升级为**结构化三态判定**（consistent / conflict / unknown）：
  SQL 维度限定三元组（列/算子/值集合）与指标侧维度声明实质比对，只有实质矛盾才判 conflict，
  **宁可 unknown 不误报**、不引入别名启发式（govio 侧，随 govio 发版生效）
- 时间粒度矛盾（声明月度取年度）纳入检测；8 档回归样本逐档锁定判定
- map 侧消费断言 46 → 77（三态透传/降级/reason 全覆盖），输出契约不变
