- **记录**：2026-11-06，T2.2 验收后用户提出
- **背景**：T2.2（PR #23）已让 SQL 节点携带 `semanticRefs`（引用的图谱指标/维度/字段标准），血缘边可区分数据/语义血缘。但指标**不显示在画布上**——只存在于节点属性里，且 SQL 节点卡片 UI 尚未渲染 refs 列表（T2.2 design.md 遗留问题 3）。用户问「指标也能显示在画布上？」由此引出本议题。
